# vidextract — разбор видео на элементы для HyperFrames

`vidextract` берёт готовый вертикальный ролик с «вшитыми» элементами (рекламный баннер, пословные
субтитры и т. п.) и раскладывает его на отдельные слои. Из этих слоёв он собирает редактируемый проект
[HyperFrames](https://github.com/heygen-com/hyperframes) (HTML → видео).

```
ролик.webm ──► vidextract ──► project/
                               ├─ index.html          композиция HyperFrames (слои на таймлайне)
                               ├─ elements.json       манифест: все найденные элементы, тайминги, стиль
                               ├─ captions.json       субтитры в формате транскрипта HyperFrames
                               └─ assets/
                                  ├─ plate.mp4        «чистый» футаж: баннер и субтитры закрашены
                                  ├─ overlay.webm     анимированный баннер с альфа-каналом (VP9)
                                  ├─ overlay_states/  PNG каждого уникального состояния баннера
                                  ├─ shots/           превью каждого шота (по склейкам)
                                  ├─ audio.m4a        звуковая дорожка
                                  ├─ fonts/, vendor/  шрифт и GSAP (рендер работает без CDN)
```

## Что извлекается

| Слой | Как находится | Во что превращается |
|---|---|---|
| **Зона оверлея** | насыщенные области с резким контуром, которые стабильно появляются в одних и тех же строках кадра | координаты зоны + доминирующий цвет |
| **Баннер** | покадровое матирование: тело по цвету → заливка дыр → присоединённые резкие детали (монеты, звёзды, персонаж) | `overlay.webm` с альфой, PNG каждого состояния, расписание смены (состояния / переходы) |
| **Субтитры** | белые глифы, обведённые тёмной обводкой по всему контуру; слова отделяются по форме, а не по размеру | HTML-текст на таймлайне, OCR (tesseract.js, `rus`), размер, цвета, толщина обводки, позиция, pop-кривая каждого слова |
| **Футаж** | инпейнтинг масок баннера и субтитров | `plate.mp4` |
| **Склейки** | гистограммы по полосам кадра без зон оверлея | список шотов + превью |
| **Звук** | — | `audio.m4a` |

## Установка

Нужны Python ≥ 3.10 и Node ≥ 22.

```bash
pip install -r requirements.txt   # numpy, opencv, imageio-ffmpeg (статический ffmpeg с libvpx/x264/dav1d)
npm install                       # hyperframes CLI, gsap, tesseract.js
```

При первом запуске русская модель OCR (`rus.traineddata`, ~15 МБ) скачивается в `~/.cache/vidextract/tessdata`.

## Запуск

```bash
python -m vidextract ролик.webm -o my_project

cd my_project
npx hyperframes lint .           # проверка композиции
npx hyperframes preview          # Studio: каждый слой и каждое слово — отдельный клип на таймлайне
npx hyperframes render -o out.mp4
```

Опции:

```
--width 1080            ширина рабочего холста (по умолчанию 1080, пропорции исходника сохраняются)
--ocr-lang rus          язык(и) tesseract: rus, eng, rus+eng
--no-ocr                без распознавания текста (слова будут #0, #1, …)
--overlay-zone 0.05:0.27   задать зону оверлея вручную (доли высоты кадра)
--caption-band 0.60:0.71   задать полосу субтитров вручную
--no-overlay / --no-captions
```

## Пример: `funpay_cliphub` (91 с, 1440×2560, AV1)

Результат разбора:

- **Оверлей**: 5 состояний баннера — `FUNPAY.COM`, «Маркетплейс / где найдёшь всё» с бегущей лентой
  иконок, «Пополняй любимые игры без переплат» с аниме-персонажем, «Никакой рутины — только фан» и
  иконка-стрелка. Они крутятся по кругу с периодом 20 с, между ними 3D-флип переходы по 0,2–1,9 с.
  Точное расписание лежит в `elements.json → layers.overlay.timeline`.
- **Субтитры**: ~165 слов по одному, Rubik-подобный жирный капс, белый `#fffdff` с чёрной обводкой
  ~8,5 px (при 1080×1920), центр кадра по X, 65,7 % по высоте. Pop-in упругий:
  масштаб ≈ 0.87 → 1.33 → 1.08 → 0.91 → 0.93 → 1.0 за 6 кадров; выход — жёсткая склейка без анимации.
- **Склейки**: 16.0, 36.0, 44.8, 63.6, 68.1 с (переходы общий ↔ крупный план, джамп-каты).

## Как устроено

```
vidextract/
  media.py     ffmpeg: probe, потоковое чтение кадров, энкодеры (H.264, VP9+alpha)
  layout.py    проход A (180 px): зоны оверлея/субтитров, цвет оверлея, склейки
  overlay.py   матирование баннера, сегментация состояний/переходов
  captions.py  детекция обведённых глифов, группировка в слова, стиль и pop-кривая
  plate.py     инпейнтинг «чистой подложки»
  ocr.py       мост к tesseract.js (js/ocr.mjs)
  compose.py   генерация проекта HyperFrames
  extract.py   проход B и сборка всего вместе
tests/test_synthetic.py   сквозной тест на сгенерированном ролике с известными слоями
```

Тест: `python tests/test_synthetic.py` (или `pytest tests`).

## Ограничения

- Эвристики рассчитаны на типичный монтаж шортсов: оверлей поверх размытой или тёмной подложки,
  субтитры белые с тёмной обводкой, по одной строке. Если зона определилась неверно, задайте её через
  `--overlay-zone` / `--caption-band`.
- Под баннером и субтитрами подложка восстановлена инпейнтингом, поэтому там она мягкая. Это нормально
  для размытого фона, но заметно на лице, если слово его перекрывало.
- Мягкие полупрозрачные части баннера (тени, свечение) в альфу не попадают.
- Шрифт субтитров подбирается как ближайший открытый (Rubik 900). Оригинальный шрифт можно подложить
  в `assets/fonts` и поменять `font-family` в `index.html`.
